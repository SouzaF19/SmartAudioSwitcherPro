# IPolicyConfig ABI reference

`PolicyConfig.cs` is a C# interop declaration of the Windows 7+ IPolicyConfig ABI, using the method order and GUIDs documented by EreTIk's PolicyConfig.h as distributed in Fred Emmott's AudioDeviceLib:
https://github.com/fredemmott/AudioDeviceLib/blob/master/src/PolicyConfig.h
